2. Reports & Disputes System

Any user can report any other profile at any time.

Five report reasons: Scam / Fraud · Fake profile · Harassment · Inappropriate content · Other

Flow: User files report → Admin + reported user + reporter all notified → Admin investigates → Confirms scam (account denied) or Dismisses → All parties notified on outcome

Reporter identity is always kept confidential from the reported user.

When Who gets notified Message
Report filed All Super Admins New report filed against [name]: [reason]
Report filed Reported user A report has been filed against your profile and is under review
Report filed Reporter Your report has been received — review within 48 hours
Admin investigates Reporter Your report is now under active investigation
Scam confirmed Reporter + Reported user Account actioned / Your account has been actioned
Report dismissed Reporter + Reported user No action taken / Report dismissed — you are cleared

3. Platform Rules

Rule Detail
🚫 No contact info in public fields Phone numbers and email addresses are automatically blocked in all public text fields (bio, achievements, captions, match updates)
📬 All contact via secure inbox No phone numbers or emails ever shown anywhere. Every interaction goes through the platform inbox.
💳 No payment requests Agents and scouts cannot charge players. Requests flagged automatically and sent to admin review.
✅ Verified badge = human reviewed Badges are not automatic. An admin reviews and approves all submitted identity and licence documents.
💰 Paid tryouts admin-reviewed All fee-bearing tryout posts are held in admin moderation queue before going live on the platform.
🎬 Full-match video required Players must upload at least one video classified as "Full Match" before verification can be approved.
🔐 Password minimum 12 characters Enforced at registration. Auth errors do not distinguish unknown accounts from wrong passwords.
📁 SHA-256 duplicate detection Duplicate file uploads are flagged automatically and visible to the admin in the Duplicates tab.
